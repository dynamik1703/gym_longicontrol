# Backup verification requirements
The initial zero state is certified. Each admitted grid action is checked at its
exact production successor and over the entire repeated -1 braking witness,
using only the observation/memory available before the proposal. Independent
reconstruction checks all certificate fields and the path hash. New information
must retain a lower envelope no smaller at any future point and no larger than
the physical route limit. The remaining witness certifies backup -1 again.
An empty menu, unavailable backup or final recertification discrepancy stops.

Synthetic checks include exact preview/sign crossings, rounding boundaries,
maximum legal speed, high-speed braking, remembered lower limits, unsafe actions
and exact executed braking after admitted proposals. V2 search tests 320 synthetic
states, all 21 actions, independent witnesses and successor backup admission.
Full V2 fixture rollouts exercise repeated maximal action and a separate minimal
(braking) rollout. Every fixture has a fresh V2 identity.

The retained V1 refreshed-preview negative control is reproduced as V2 evidence:
v=25.6625 m/s, +1, unseen 20 km/h sign at 150.000001 m. Giving the successor an
unobserved fresh 150 m admits a violating brake endpoint; the intended old-frontier
certificate rejects it. This is not a falsification of the intended invariant
or a claim about the original capped controller's reachable states.
