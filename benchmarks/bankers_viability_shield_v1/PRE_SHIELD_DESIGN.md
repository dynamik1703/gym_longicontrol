# Admission design

BankersShield.certify(observation, causal_memory, native_action) returns the exact successor, endpoint gate, known/unknown backup results, witness identity and digest, finite-prefix count/terminal state, numerical margins, causal input digest, rejection reason, proof class, source/configuration identity and exact physics count. The verifier regenerates the transcript without calling certify. Nonfinite inputs and physical predictions fail closed.

CausalMemory ingests only the ordinary 8-vector and previously executed actions. It propagates the full production state from reset. It maintains a compact piecewise constant limit lower envelope as the pointwise maximum of observation-derived lower bounds. No Track, seed, environment, oracle or future state enters admission. Source/configuration identity is frozen before scientific execution.

The proposed successor and entire maximum-braking suffix are tested using pre-action information. This includes known signs crossed in a native step, unknown-preview latency and consecutive reductions. SpeedCertificate has no deadline assertion. The inherited heuristic completion bound is a separate, explicitly applicable diagnostic in comparison records.

SafeActionSet certifies exactly [-1.0,-0.9,...,1.0]. Every accepted grid point is individually checked. No safety claim covers interpolated points or the whole continuous interval. Fewer actions may reduce attainable energy/progress quality; the original continuous-action environment remains unchanged. No continuous interval proof is needed for V1.

PreShield.prepare exposes the mask before selection. select(index) rejects invalid indices, repeats the full native certificate and requires identical results/digests. Any discrepancy stops execution. observe_executed_action advances memory only for the verified action. Mask emptiness or absent -1 in a reachable certified state stops execution.

Matched inherited comparison applies the original four predicate implementations to identical native proposals and causal states. Its native proposal adapter is study-specific; the historical target-speed controller is not modified. B proposes +1, then uses the frozen CAUSAL60 replacement on rejection. C follows the same descending preference within the precomputed mask. The old 60 km/h proposal cap is not a safety theorem and is disclosed separately from predicate comparisons.
