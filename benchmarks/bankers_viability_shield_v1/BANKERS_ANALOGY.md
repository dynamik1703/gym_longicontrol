# Mathematical translation

A resource request becomes a proposed native action. A safe allocation becomes an information state with an executable backup witness. Admission requires the successor to preserve that witness. This is predictive safety filtering and robust controlled invariance, not the operating-system Banker's Algorithm and not an algorithmic novelty claim.

The quantifiers are **there exists one causal backup policy, for all unseen continuations consistent with observation and generator assumptions, for all subsequent native steps**. No route-specific oracle plan is substituted for the causal policy.
