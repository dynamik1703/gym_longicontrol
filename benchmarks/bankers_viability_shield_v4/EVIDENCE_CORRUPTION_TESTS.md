# Corruption and interrupted writes

See tests.xml and quality_1.log: mask bit, rejection reason, backup hash, successor position (one ULP), numerical margin, native signed energy, full executed action, configuration identity, record count, record order, native timestamp, lifecycle flag, deadline diagnostic, valid prefix, selected certificate and missing field are all rejected. Semantic corruption is tested independently of an unchanged container hash. Separate tests cover envelope record-count tampering, strict JSON duplicate/nonfinite rejection, immutable publication interruption and a real process exit before publication. The crash leaves only an orphan temporary file, never a published scientific artifact. STARTED timestamp mutation, rerun and ambiguous STARTED reopening are rejected. Monkeypatching both online classifiers to fail does not prevent independent replay. Preliminary unit-test failure was a tuple/list test assertion, corrected before scientific execution; its original log is retained.
