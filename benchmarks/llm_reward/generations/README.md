# Generated reward candidates

This directory is intentionally empty apart from this notice in Phase 1.

Future ingestion creates `g0/`, `g1/` and `g2/` directories containing
versioned candidate source and metadata. Do not manually add or edit reward
formulas here. Candidate IDs and hashes are assigned by
`benchmarks.llm_reward.candidate_validation`.

No actual LLM reward candidate has been generated, ingested, screened or
selected as part of the infrastructure freeze.
